# محتوى Urate للسوشال ميديا

فيديوهات موشن وكيروسيلات وبوستات لتطبيق Urate، صُنعت بالكامل عبر تطبيق **مصنع المحتوى**.

الصفحة: https://alshala7i.github.io/urate-content/

- `index.html` — صفحة العرض والتحميل (فيديوهات موشن، قصص مرسومة، كيروسيلات، بوستات)
- `m/` — نسخ مضغوطة للعرض داخل الصفحة
- `dl/vid/` — الفيديوهات بالدقة الكاملة: تيكتوك وريلز 9:16 (1080×1920) وانستقرام فيد 4:5 (1080×1350)
- `dl/img/` — الصور: انستقرام 4:5 (1080×1350) وتيكتوك/ستوري 9:16 (1080×1920)
- `dl/zip/` — كل كيروسيل بملف مضغوط لكل مقاس مع الكابشن

## نسخة المعرض بلا تعليق صوتي — `expo/`

للشاشة الطولية في المعرض (https://trycf.app/urate): نفس الفيديوهات بالموسيقى والمؤثرات وحدها.

- `expo/<ID>.mp4` بدقة 1080×1920 · `expo/720/<ID>.mp4` نسخة أخف — الصورة منسوخة كما هي بلا إعادة ترميز، والصوت وحده جديد (−14 LUFS).
- **V5–V12 · R1–R6:** الصوت مفصول بالذكاء الاصطناعي (Demucs `htdemucs_ft` — MIT) · والموسيقى كانت تنخفض تحت الكلام (ducking) فرُفعت لمستواها
  بنفس معاملات محرّك الرندر (`audio.py` · `R_cutdowns/build.py`) · المؤثرات المعروفة من المكتبة تُركت بمستواها.
- **S1–S8:** القصص كانت بلا موسيقى (صوت فقط) ⇒ موسيقى جديدة مولّدة بالكود (`musicbed.py` من مصنع المحتوى — MIT · بلا حقوق) · لكل قصة مقام ونمط.
- **V1–V4** أصلاً بلا تعليق صوتي ⇒ لا نسخة لها هنا (الصفحة تستعمل الأصل).
