# محتوى Urate للسوشال ميديا

فيديوهات موشن وكيروسيلات وبوستات لتطبيق Urate، صُنعت بالكامل عبر تطبيق **مصنع المحتوى**.

الصفحة: https://alshala7i.github.io/urate-content/

- `index.html` — صفحة العرض والتحميل
- `m/` — نسخ مضغوطة للعرض داخل الصفحة
- `dl/vid/` — الفيديوهات بالدقة الكاملة: تيكتوك وريلز 9:16 (1080×1920) وانستقرام فيد 4:5 (1080×1350)
- `dl/img/` — الصور: انستقرام 4:5 (1080×1350) وتيكتوك/ستوري 9:16 (1080×1920)
- `dl/zip/` — كل كيروسيل بملف مضغوط لكل مقاس مع الكابشن
